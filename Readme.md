# Novi

A calm workspace for small, fast-moving teams. Novi is a project management dashboard built with Next.js, featuring a landing page, drag-and-drop task management, calendar views, and a clean modern UI.

## Tech Stack

- **Framework:** Next.js 16 + React 19
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS 4
- **Drag & Drop:** @dnd-kit
- **Calendar:** FullCalendar
- **Animations:** Motion (Framer Motion)
- **Icons:** Lucide React

## Prerequisites

- **Node.js** — v20.0.0 or later (v22+ recommended)

## Clone the Repo

```bash
git clone https://github.com/ujwalbholan/novi.git
cd novi
```

## Install Dependencies

### npm

```bash
npm install
```

### yarn

```bash
yarn install
```

### pnpm

```bash
pnpm install
```

### bun

```bash
bun install
```

## Run the Dev Server

### npm

```bash
npm run dev
```

### yarn

```bash
yarn dev
```

### pnpm

```bash
pnpm dev
```

### bun

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.
